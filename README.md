# java-calculator-precourse

# 프로젝트 개요
사용자가 입력한 문자열에 포함된 숫자들을 구분자에 따라 분리해 합을 계산하는 프로그램을 구현한다.
입력값이 잘못된 경우 예외를 발생시키며, 모든 테스트를 통과해야 한다.


# 구현 기능 목록
1. 입력 처리
- [ ] camp.nextstep.edu.missionutils.Console.readLine()을 사용해 문자열 입력을 받는다.
- [ ] 입력 안내 문구 : 덧셈할 문자열을 입력해 주세요.

2. 빈 문자열 처리
- [ ] 사용자가 빈 문자열""을 입력하면 0을 반환한다.

3. 기본 구분자 처리
- [ ] 입력값에 쉼표(,) 또는 콜론(:)이 포함된 경우 해당 구분자로 문자열을 분리한다.
- [ ] 분리된 숫자들을 모두 더한 값을 반환한다.

4. 커스텀 구분자 처리
- [ ] 문자열 앞부분에 "//"와 "\n" 사에ㅣ에 커스텀 구분자가 존재할 경우 해당 문자를 구분자로 사용한다.

5. 예외 처리
- [ ] 숫자가 아닌 문자가 포함된 경우 IllegalArgumentException을 발생시킨다.
- [ ] 음수 입력이 포함된 경우도 예외를 발생시킨다.
- [ ] 예외 발생 시 프로그램을 종료하지 않고 적절한 예외 메시지를 출력한다. (System.exit() 사용 금지)

6. 출력
- [ ] 계산된 합계를 하단 형식으로 출력한다.
- [ ] 결과 : 6
